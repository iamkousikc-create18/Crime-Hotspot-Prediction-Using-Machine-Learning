# 🚨 Crime Hotspot Prediction Using Machine Learning

### An Intelligent Data-Driven Approach to Crime Analysis and Hotspot Prediction

## 📌 Project Overview

Crime Hotspot Prediction Using Machine Learning is a data science project focused on analyzing crime patterns and identifying potential crime hotspots using historical crime data.

The project aims to explore crime trends, understand geographical crime distributions, and apply machine learning techniques to support data-driven crime analysis.

By combining Exploratory Data Analysis (EDA), data visualization, and machine learning, this project provides insights into crime patterns and helps identify areas that may require greater attention.

## 🎯 Project Objectives

- Analyze historical crime data to identify meaningful patterns and trends.
- Perform Exploratory Data Analysis (EDA) to understand crime distributions.
- Identify geographical areas with higher crime concentrations.
- Apply machine learning techniques for crime hotspot prediction.
- Visualize crime patterns and analytical findings.
- Develop an interactive application for exploring crime-related insights.

## 💻 Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/iamkousik-create18/Crime-Hotspot-Prediction-Using-Machine-Learning.git
```

### 2. Navigate to the Project Directory

```bash
cd Crime-Hotspot-Prediction-Using-Machine-Learning
```

### 3. Create a Virtual Environment (Optional)

```bash
python -m venv venv
```

Activate the environment:

**Windows:**
```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Jupyter Notebook

```bash
jupyter notebook
```

Open `Crime Hotspot Prediction.ipynb` to explore the complete analysis and implementation.

### 6. Run the Streamlit Application

```bash
streamlit run streamlit_app/app.py
```

*Note: Update the application filename in this command if your Streamlit entry-point file has a different name.*
