# Dataset Information

This folder contains the sample dataset used in the Crime Hotspot Prediction project.

## 1. Dataset Overview

- **Dataset Name:** Chicago Crime Dataset
- **Location:** Chicago, Illinois, USA
- **Time Period:** January 1, 2022 – December 31, 2022
- **Data Format:** CSV
- **Original Source:** City of Chicago Data Portal

## 2. Dataset Source

The dataset was collected from the official City of Chicago Data Portal.

**Official Source:**  
https://data.cityofchicago.org/Public-Safety/Crimes-2001-to-Present/ijzp-q8t2

## 3. Full Dataset

The complete dataset (`chicago_crime_2022.csv`) is hosted on Google Drive because of its large file size.

**Google Drive Download:**  
[Download Full Dataset](https://drive.google.com/file/d/1UtZdFIsawbg0_aZQp0jX9dRgfXH7VJGW/view?usp=sharing)

## 4. Sample Dataset

A smaller sample of the original dataset is provided in this folder for reference and demonstration purposes.

**File:** `chicago_sample.csv`

## 5. Dataset Usage

The original dataset contains crime records from 2022 and was used for:

- Crime pattern analysis.
- Exploratory Data Analysis (EDA).
- Spatial hotspot detection using DBSCAN.
- Crime count prediction using Machine Learning.
- Hotspot classification and evaluation.

## 6. Important Note

The sample dataset is provided for reference purposes. To reproduce the complete project workflow, download the full dataset from the Google Drive link above.

**Data Attribution:** City of Chicago Data Portal – Crimes, 2001 to Present.
